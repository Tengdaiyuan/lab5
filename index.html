Lab 5 – HTML5 Practical Exercises

Three small browser demos built with plain HTML, CSS and JavaScript — no frameworks, no build step.

  • Exercise 1 – The HTML5 Canvas

    A smiley face and its caption, painted with the Canvas 2D API.

  • Exercise 2 – HTML5 Geolocation

    Read the device position with navigator.geolocation and show the coordinates.

  • Exercise 3 – To-Do List with Local Storage

    Add and remove tasks that persist across browser sessions.
